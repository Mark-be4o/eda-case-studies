# Eda Case Studies

Exploratory data analysis case studies: cafe sales, Spotify tracks, hotel bookings and student burnout.

## What it does

Four data analysis notebooks, each covering cleaning, KPIs and visualizations. The cafe sales notebook works on a deliberately dirty dataset, the hotel notebook studies booking demand, and the student burnout notebook adds a prediction model.

## Files

- `cafe_sales_analysis.ipynb`
- `spotify_track_analysis.ipynb`
- `hotel_booking_demand_analysis.ipynb`
- `student_burnout_prediction.ipynb`

## Tools

pandas, numpy, Plotly, seaborn, matplotlib, scikit-learn, kagglehub

## Dataset

Kaggle: [Cafe Sales (dirty data)](https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training), [Spotify Tracks](https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset), [Hotel Booking Demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand), [AI Impact on Students](https://www.kaggle.com/datasets/laveshjadon/ai-impact-on-students)

The dataset is not included in this repo.

## Results

The saved notebook copy has no recorded metrics. Run it to reproduce them.

## How to run

1. Open the notebook in Google Colab or Jupyter.
2. Install dependencies: `pip install -r requirements.txt`.
3. Download the dataset from the link above (some notebooks fetch it with `kagglehub`, which asks for Kaggle credentials) and update the data path if needed.
4. Run all cells.
